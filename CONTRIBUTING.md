# Contributing

1. Fork this repository.
2. Copy the relevant template from `/templates/` into `/entries/poisons/` or `/entries/venoms/`.
3. Fill in every field. `sources`, `mechanism_of_toxicity`, and `treatment` are required — a PR will fail CI without them.
4. Open a pull request describing the change.
5. A reviewer will check sourcing and accuracy before approving.

This site is reference information, not medical advice. In a real exposure or poisoning event, contact emergency services or a poison control center.
